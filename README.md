# Generador de Clave Cifrada

## Descripción
Aplicación de consola en Java que genera una clave de hasta 10 caracteres extrayendo el último carácter de cada línea de un archivo de texto.

## Funcionalidades
- Leer archivo "fichero.txt"
- Extraer el último carácter de cada línea
- Construir una clave con un máximo de 10 caracteres
- Guardar la clave generada en "clave_cifrada.txt"
- Mostrar la clave por pantalla

## Tecnologías
- Java
- ArrayList (Character)
- BufferedReader / FileReader
- BufferedWriter / FileWriter
- Manejo de excepciones IOException
